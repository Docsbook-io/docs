# Planning

Documentation that fails rarely fails sentence by sentence. It fails because the page set was decided by what was easy to write — the feature list, the API surface — rather than by what somebody arrives needing.

The reading that most often changes the plan is not in this section: it is [demand gaps](../auditing/demand-gaps.md), the audit of readers who never arrived. A page that does not exist has no traffic, so no number will ever point at it.
