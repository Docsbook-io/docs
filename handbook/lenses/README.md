# The fourteen lenses

A documentation site can be read fourteen different ways, and each reading finds a defect the others are structurally blind to. Internal linking cannot see a page that was never written. Jobs-to-be-done cannot see a robots rule. Search intent cannot see that a correct page uses a word no reader would type.

**Do not run all fourteen.** A fourteen-part report is one nobody finishes, and it buries the two findings that mattered. [Choosing a lens](../auditing/choosing-a-lens.md) decides which two to four a given question and a given set of available evidence actually justify.

Each page below has the same shape, deliberately: what the lens exclusively owns and what it explicitly does not, when the pass earns its place, how to grade the evidence it produces, the readings themselves, and a severity table. That sameness is what makes fourteen pages navigable instead of fourteen essays.
