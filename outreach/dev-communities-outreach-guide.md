# Outreach: Dev Slack/Discord Communities (15-20 Communities)

**Goal:** Post about Docsbook to developer communities without requiring signup or permission (or with minimal friction).

**Why these communities?** Developers who document (open-source, startups, indies) are the core audience for a doc-generation tool.

## Posting Strategy Guide (No Signup / Low Friction)

### **Phase 1: Preparation**
1. Craft 3 variations of message (short 1-liner, medium paragraph, long with screenshot)
2. Prepare 2-3 assets:
   - Demo GIF of Docsbook in action
   - One-liner value prop
   - Link to loom video or screenshot

### **Phase 2: Posting Protocol**

#### **Best Time to Post**
- **US timezones:** 9-11 AM PT, 12-2 PM ET
- **EU timezones:** 10 AM CET
- **Check:** Which timezone the community is most active in

#### **Message Template (Adapt per Community)**

**For AI/Dev communities:**
```
🚀 I built Docsbook — AI-powered docs generation for GitHub repos

Problem: Your docs are buried in README / scattered in folders
Solution: Point Docsbook at your GitHub → instant SEO-friendly docs site

Every update to your repo auto-syncs. Built-in AI chat. 15-language translation.

No CI/CD. No config. Just GitHub + Docsbook.

🔗 docsbook.io
🎥 [Demo video link if available]
```

**For Indie Hacker communities:**
```
Show HN / Show IH: Built Docsbook (doc generator for GitHub) in 6 months

How it works:
- User pastes github.com/owner/repo
- Docsbook creates docs.yourcompany.com instantly
- Updates on every push

Revenue model: Free tier + $150 lifetime PRO + $59/mo PRO+

Metrics: 2,400+ workspaces, 180K pages indexed

[Demo link]
```

**For Technical/Framework communities:**
```
Building a React / Next.js / Vue library? 

Docsbook auto-generates SEO docs from your GitHub README or docs/ folder.

No setup. No CI. Just works.

Available via MCP server for AI agents (Claude, Cursor).
```

#### **No-Signup Required Tactics**

| Community Type | How to Post Without Signup |
|---|---|
| **Slack** | Join via public invite link (no signup) → post in public channels |
| **Discord** | Join via public invite → post in designated channels (#showcase, #announcements) |
| **HN** | Create free account (email only), post to relevant thread or "Show HN" |
| **IH** | Create free IH account (minimal), post in #launches or start a discussion |
| **GitHub Discussions** | Any logged-in GitHub user can post (if account exists) |
| **Product Hunt** | Free account (email) → launch day post |
| **Twitter/X** | Post directly (if account exists) |
